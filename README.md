# TastyGo – Food Ordering Website

TastyGo is a responsive food ordering website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly interface for exploring food items and navigating the online ordering process.

## Features

- User-friendly homepage
- Food menu browsing
- Shopping cart interface
- Login and registration pages
- Payment page interface
- Responsive website design
- Interactive frontend functionality using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Homepage
- `menu.html` – Food menu
- `cart.html` – Shopping cart
- `login.html` – User login
- `signup.html` – User registration
- `payment.html` – Payment interface
- `css/` – Stylesheets
- `js/` – JavaScript files

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website.
